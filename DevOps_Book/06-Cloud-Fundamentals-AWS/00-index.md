# Cloud Fundamentals (AWS) — Complete Course Index

> **DevOps Learning Path — Topic 6 of 11**

AWS is the world's leading cloud platform with 33% market share. This course takes you from zero cloud knowledge to being able to architect and operate production applications on AWS. You'll understand the core services every DevOps engineer uses daily, how to design secure and cost-effective infrastructure, and how AWS integrates with the CI/CD pipelines you built in Topic 5.

---

## What You'll Be Able to Do

By completing this course you will be able to:

- Launch and manage EC2 instances and auto-scaling groups
- Design VPCs with public/private subnets, security groups, and NACLs
- Configure IAM users, roles, and policies following least privilege
- Store and serve files with S3, including static websites and CDN
- Set up managed databases with RDS and caching with ElastiCache
- Monitor infrastructure with CloudWatch alarms and dashboards
- Deploy serverless functions with Lambda and API Gateway
- Use the AWS CLI to automate everything
- Estimate and optimize AWS costs
- Pass AWS Solutions Architect Associate exam concepts
