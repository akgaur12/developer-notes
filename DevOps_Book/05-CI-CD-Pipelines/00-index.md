# CI/CD Pipelines — Complete Course Index

> **DevOps Learning Path — Topic 5 of 11**

CI/CD (Continuous Integration / Continuous Delivery/Deployment) is the practice of automating software delivery from code commit to production. This course teaches you to design, build, and maintain pipelines that test, build, scan, and deploy software reliably.

---

## What You'll Be Able to Do

By completing this course you will be able to:

- Design and implement CI/CD pipelines from scratch
- Build automated test and build pipelines with GitHub Actions
- Build and push Docker images in CI
- Implement deployment strategies (rolling, blue/green, canary)
- Manage secrets securely in pipelines
- Configure GitLab CI and Jenkins
- Optimize pipeline performance (caching, parallelism)
- Debug broken pipelines quickly

---

## Prerequisites

- Git & Version Control (Topic 3)
- Docker (Topic 4)
- Basic Linux command line
